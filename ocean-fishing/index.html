オーシャンフィッシング魚図鑑

パッチ7.5x対応。出航予定から便を選ぶと、その便の3つの釣り場の時間帯で釣れる魚とねらい目を表示します。全13海域260件の餌・引き(!の数)・待ち秒数つき。

--:--:-- 日本時間・出航予定は自動で更新

    各海域の幻海流トリガー（通常時に釣ると幻海流が発生しうる魚）、通常時の直感魚、幻海流のヌシ（伝説魚）と、ヌシが狙える航路。

    各釣り場の時間帯は航路パターンで固定です（ゲームデータ IKDRoute より）。航路名の（）は最後の海域の時間帯。幻海流のヌシが出る時間帯に当たる海域には★を付けています。

    見方

    • 秒数：キャストしてから魚が食いつくまでの秒数（撒き餌なし）。撒き餌を使うと短くなります。餌によって秒数が変わる魚がいるので、餌別に載せています。「—」はその餌では掛からない（記録なし）という意味です。
    • 推奨餌：その魚が最も掛かりやすい餌。「泳がせ:〇〇」は〇〇を釣ってから泳がせ釣りで狙う魚です。
    • 引き：竿のしなりの「!」の数。チップの「プレシジョン／ストロング」は向いているフッキングです。
    • 条件：天候条件は通常時の魚だけ、時間帯条件は幻海流の魚だけにあります。各海域の時間帯は航路パターンで決まります（「航路と時間帯」タブ）。
    • DH/TH：ダブルフッキング／トリプルフッキングで釣れる数。TC実測はTeamcraft利用者の記録による全餌合算の幅（参考値）。

    予定表について

    • 受付は日本時間の奇数時（1時、3時…23時）ちょうどに始まり、15分で締め切って出航します。近海航路・遠洋航路とも2時間ごとに1便です。
    • 行き先と時間帯は決まった周期（144便＝12日）で回ります。近海航路は Lulu's Tools が公開している計算式、遠洋航路はパッチ7.5以降の周期（クガネ方面6種とサベネア島行き3種がほぼ交互）で計算しています。FFXIV Fieldcraft の運行表と照らし合わせて、近海航路12便すべてと遠洋航路の次回出航が一致することを確認済みです。
    • 天候は便ごとにランダムに決まり、出航前には分かりません（同じ時刻の便でも船ごとに違います）。各釣り場に着いたら、その時の天候をタップすると、その天候で釣れない魚を外して表示します。幻海流が終わると天候は快晴になり、幻海流トリガーの魚は釣れなくなります。

    古い情報への注意

    • パッチ7.5（2026年4月28日）で遠洋航路に「サベネア島行き」（名もなき島沖合 → セイレーン海沖合 → サベネア島沖合）が追加されました。7.5以前の攻略記事には名もなき島沖合・サベネア島沖合の魚が載っていません。
    • Lulu's Tools の魚一覧（日本語版）は、確認時点で名もなき島沖合・サベネア島沖合が未収録でした。
    • 名もなき島沖合・サベネア島沖合のデータは 2026年5月1日時点の収集データで、元サイトでも「調整中」とされています。推奨餌が資料によって違う魚：サベネアンサウルス（ファットワーム／クリル）、ヒマヒマヒ（ファットワーム／イワイソメ）。アクパーラの待ち秒数は資料により8秒〜12秒。
    • ダブル/トリプルの数が資料で違う魚：ブラックヘリコプリオン、ジェイドマンティス（4/7 と 2/3）。本表は 4/7 を採用。

    どう照合したか

    • 海域ごとの魚の顔ぶれ・日本語名・航路パターンは、ゲームデータ（XIVAPI 経由の IKDSpot／FishingSpot／IKDRoute）から取得し、26の釣り場すべてで魚10種が一致することを確認しました。
    • 餌・秒数・引き・得点・条件は Console Games Wiki の釣り手帳ページ（ffxiv.oceanfishing.boats／Tyo'to Tayuun 氏のデータ）を主に使い、旧海域22か所220件は Lulu's Tools と、7.5海域は FFXIV Fieldcraft と突き合わせました。引き・得点・条件の食い違いは上記以外ありませんでした。
